VELXTRIA V58 — ONE-CLICK LOCAL LAUNCHER

Windows: double-click START_VELXTRIA_WINDOWS.bat
macOS/Linux: run START_VELXTRIA_MAC_LINUX.command

No Cursor, IDE, or code editing required.

IMPORTANT: This is NOT a self-contained Windows EXE. Python 3 must be installed on the computer. Some optional VELXTRIA features may also need packages listed in velxy-main/requirements.txt. The launcher starts the local server and opens your default browser. Keep the launcher terminal open while using VELXTRIA. Close it to stop the server.

Local URL: http://127.0.0.1:8878/sovereign-singularity-v58

Security: Intended for trusted local machines. Do not expose port 8878 to the public internet. Back up your database before upgrading. The local launcher does not add desktop packaging or production hardening.

For a truly no-Python installation, a Windows executable must be compiled and tested on a Windows build machine (e.g., with PyInstaller). This archive does not claim to contain such an executable.
