# VELXTRIA V18 — Project Infinity

Open `/infinity` in local SQLite studio mode. Publish an application in Singularity X, then export its offline validation workbench. Follow `INFINITY_GUIDE.md` in the exported ZIP.

Features: baseline/candidate Docker test comparison, explicit release gate, checksummed immutable candidate ZIP, change diff, historical evidence. No automatic AI repair, unattended retries, cloud deployment, or production execution.

Preserve the existing `VELXTRIA_DATA_DIR` and back up your SQLite database before switching versions. This project ZIP does not include a live database.
