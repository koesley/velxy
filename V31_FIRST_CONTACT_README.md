# VELXTRIA V31 — Project First Contact

Local pilot issue tracking built on V30. Visit `/first-contact` in local studio mode.

- Workspace-isolated pilot issue records, severity, and resolution status.
- Owners and editors can create/resolve; viewers can inspect.
- Existing Launchpad feedback remains in Launchpad; First Contact links to it.
- No external invitation service, browser certification, or production deployment.
- Back up the SQLite database before upgrading. Existing data directory is controlled by `VELXTRIA_DATA_DIR`.
