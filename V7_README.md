# VELXTRIA V7 — Project Omniscience

Adds durable, approval-gated internal workflow orchestration to V6's Ollama-generated strategies. Go to `/omniscience` after generating a plan at `/singularity`. Each saved plan can be imported once, creating ordered tasks. Approve a task, then manually record its completion with a factual note. Earlier tasks must be completed before later tasks can be recorded completed. All transitions are audited.

## Data safety

The archive does not include `portal.sqlite3`. Back up the currently working database before launching, and point `VELXTRIA_DATA_DIR` to the existing data folder. The upgrade creates only three new `vx7_*` tables. Existing Gerate missions and evidence remain in their current tables. Do not copy an empty database over the existing one.

## Local launch

Install Ollama and pull a local model (e.g. `ollama pull llama3.2`) to generate new V6 strategies. In PowerShell, open the extracted `velxy-main` folder, set `VELXTRIA_LOCAL_STUDIO=1`, `VELXTRIA_DEPLOYMENT_MODE=local`, `VELXTRIA_REQUIRE_PERSISTENCE=0`, and set `VELXTRIA_DATA_DIR` to your confirmed existing data directory. Then run `python portal.py` and visit `http://127.0.0.1:8878/omniscience`.

## Boundaries

This is an internal orchestration foundation, not a fully autonomous multi-agent system. Specialist roles are labels assigned to plan tasks; no independent agents, scheduling, external communication, financial transactions, CRM changes, or automatic verification occur. Tasks generated by AI are untrusted proposals. An owner must explicitly approve and record work. The audit log records local owner actions only.
