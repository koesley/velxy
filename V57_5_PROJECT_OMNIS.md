# VELXTRIA V57 — Project OMNIS (Omniverse + Opportunity Radar)

Includes V56 Nexus 8 plus V57.1 persistent local job ledger, V57.2 Living Business Graph, V57.3 Intelligence Council, V57.4 Decision Laboratory and V57.5 Opportunity Radar.

## Launch
Back up the existing database first. Set `VELXTRIA_LOCAL_STUDIO=1` and `VELXTRIA_DEPLOYMENT_MODE=local`, run `python portal.py`, sign in, and visit `/sovereign-omniverse-v57`, `/sovereign-business-graph-v57`, `/sovereign-council-v57`, `/sovereign-lab-v57`, and `/sovereign-opportunities-v57`.

## Important limitations
Opportunity Radar uses deterministic rules on manually curated business relationships. It does not independently verify claims, forecast profit, execute external actions, or run LLM agents. Scenario estimates are user-supplied assumptions, not calibrated forecasts. This is a local development build, not a production-certified SaaS. Keep existing payment secrets and database backed up.
